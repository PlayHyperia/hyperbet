| Risk                                         | Required mitigation/evidence                                                                                                                   | Owner               | Status                                                                                                            |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Smart-contract defect                        | independent audit, remediation, fresh validator/security suite                                                                                 | Security            | Open                                                                                                              |
| Upgrade/config authority compromise          | controlled custody, threshold approval, rotation drill, identity monitoring                                                                    | Operations          | Open                                                                                                              |
| Reporter/finalizer/operator compromise       | distinct least-privilege keys, alerting, pause/recovery drill                                                                                  | Operations          | Open                                                                                                              |
| RPC outage/history loss                      | redundant archival providers, retention check, fail-closed index readiness                                                                     | Infrastructure      | Local finalized-history recovery check passes; redundant archival public-provider retention drill open            |
| Stream/feed discontinuity                    | authenticated continuity/replay, terminal replay fingerprint, retention alert, authority failover proof                                        | Game/Backend        | Locally mitigated; staging failover open                                                                          |
| Keeper crash or contradictory terminal input | durable queue, leases, terminal replay fingerprint, quarantine, process-kill drill                                                             | Backend             | Locally mitigated; connected staging open                                                                         |
| Dispute-evidence custody or loss             | immutable versioned package, independent verification, production retention/access policy, public-cluster history, retrieval drill, review     | Operations/Security | Local package and re-verification pass; clean public release, retention policy, external review, and runbook open |
| Accounting/parser mismatch                   | finalized evidence validation, immutable index, reconciliation, invariants                                                                     | Backend/Security    | Local finalized database/chain/custody reconciliation passes; public staging and independent audit open           |
| Empty user-balance rent stranding            | terminal-only exact-zero close instruction, consumer cleanup, lifecycle evidence                                                               | Contract/Client     | Locally mitigated; audit/staging open                                                                             |
| Order-book state-sequence defect             | six-seed baseline plus four-seed generalized corpus, shrinking/replay, mixed-price and repeated 50-match continuation matrices, staging, audit | Contract/Security   | Arbitrary ordering and two continuations locally mitigated; longer-chain/soak open                                |
| Browser/3D/stream performance regression     | device matrix, sustained soak, telemetry budgets                                                                                               | Client/Game         | Five-minute full-topology local qualification passed; device matrix/extended production-equivalent soak open      |
| Real-value regulatory exposure               | counsel-approved jurisdiction, age, identity, sanctions, responsible-use controls                                                              | Legal/Compliance    | Open                                                                                                              |
| Incident-response failure                    | on-call ownership, alert delivery, rollback/pause/recovery drills                                                                              | Operations          | Open                                                                                                              |

No open risk is implicitly accepted. Every launch exception requires a named owner, expiry, evidence, and explicit approval.
